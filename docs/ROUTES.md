# Карта страниц
- `/` — главная страница.
- `/history` — краткая историческая справка.
- `/library` — полный архив.
- `/library?category=Техники` — фильтр по категории.
- `/ninja/hanzo` — пример динамической карточки.
- `/logreg` — регистрация и вход.
- `/profile` — закрытая личная страница.
- `/training` — закрытый тренировочный раздел.
- `POST /logout` — завершение сессии.
